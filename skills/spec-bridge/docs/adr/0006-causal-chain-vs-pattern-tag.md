# 因果链与模式标签是两个正交维度

"连环错"（修 A 暴露 B，因果 DAG）和"一错再错"（同类问题在不同处反复，聚类）是两种现象，混同建模会让两个维度都表达不清。因果链由 follow-up 父引用构成（纵向）；模式标签由 `.bridge.yaml` 的 `tags:` 自由文本字段构成（横向），`bridge pattern --tag <t>` 跨变更检索聚合。两者互不替代、互不依赖。

## Consequences

- 同一个 follow-up 可以既挂在因果链上（有 parent）又带模式标签（有 tags）——两个轴独立查询。
- 根因记录采用混合触发：单点 bug 不记；模式重复 / 暴露设计缺陷 / 连环因果必记。
